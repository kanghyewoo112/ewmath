# 은우의 수학탐험

은우(6살)가 수학책 한 단원을 마친 뒤 아빠와 함께 태블릿으로 푸는 복습 퀴즈 홈페이지입니다.

- 접속: https://kanghyewoo112.github.io/ewmath/
- 구성: 1~10권 × 30마을(하루에 한 마을) = 300마을. 책의 12주를 2~3마을씩 나눠 담습니다. 마을을 통과하면 다음 마을이 열리고, 30번 마을을 통과하면 다음 권이 열립니다.
- 문제: 마을마다 15문제이고, 문제는 미리 정해져 있습니다(다시 풀 때는 보기 순서만 바뀝니다).
  - 1~5번 복습: 쉬운 단계, 현재 주차와 앞선 두 주차에서
  - 6~10번 현재 내용의 중간 단계
  - 11~15번 단계별로 어려워지는 문제 (마지막 15번이 가장 어려운 심화)
  - 연산·사고력·도형·교과·선행·심화 6영역을 섞어 냅니다. 퀴즈를 마치면 풍선 놀이로 마무리합니다.
- 통과 기준: 15문제 중 10문제를 한 번에 맞히면 별 1개, 14문제 별 2개, 15문제 별 3개.
- 아빠 모드: 위쪽 로고를 3초 안에 5번 누르면 모든 마을이 열립니다. 다시 5번 누르면 꺼집니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 홈페이지 전체 (화면·퀴즈 진행·진행 기록) |
| `data/quiz.js` | 퀴즈 데이터. 직접 고치지 말고 아래 명령으로 다시 만듭니다 |
| `tools/build_quiz.py` | 책 코드에서 `data/quiz.js`를 만드는 스크립트 (마을별 15문제 배정) |
| `tools/qlib.py` | 문제 만들기 부품 (보기 만들기, 그림, 난이도 점수) |
| `tools/verify_quiz.py` | 최종 확인: 같은 문제가 없는지, 문제 모양이 맞는지 검사 |
| `tools/book1_data.py` | 1권 마을별 문제 종류와 확인 문제 (1권은 문제표가 없어서 따로 둡니다) |
| `eunwoo_math_code/` | PDF 교재를 만드는 원본 코드(v2). `bk2~bk10.py`가 2~10권 |

## 매달 책을 새로 만든 뒤 퀴즈 갱신하기

1. `eunwoo_math_code/`의 `bk*.py`, `content*.py`, `probs*.py`를 고쳐서 PDF를 다시 만들고 확인합니다.
2. 퀴즈 데이터를 다시 만들고 최종 확인을 합니다.

   ```bash
   python tools/build_quiz.py
   python tools/verify_quiz.py
   ```

3. 브라우저에서 `index.html`을 열어 확인한 뒤 커밋하고 push 하면 홈페이지에 반영됩니다.

`verify_quiz.py`가 통과하면 "300개 마을 × 15문제 = 4,500문제에 같은 문제가 없습니다."가 나옵니다. 하나라도 겹치면 위치를 알려 주고 실패합니다.

## 만드는 방식

- 문제 틀: v2 코드의 `bk*.py`는 문제를 "문장 틀 + 변수 범위 + 정답식"(`fam.py`)으로 정의합니다. 같은 틀에서 숫자만 바꿔 문제를 여러 개 뽑고 정답은 코드가 계산합니다.
- 보기 만들기: 정답이 숫자·짝 고르기인 문제는 터치 보기 문제로 바꾸고, 그 밖의 글 정답은 같은 틀의 다른 문제 정답을 오답 보기로 씁니다. 정답이 하나로 정해지지 않는 열린 문제는 "정답 보기 → 말했어요" 아빠 확인 카드로 둡니다.
- 연산·시계·자·분수 그림: `gen.py`·`gen2.py`의 생성기를 쓰고, 새 종류(분수·소수·약수·비율 등)는 생성기가 만든 수식을 그대로 크게 보여 줍니다.
- 난이도: 문제마다 종류·숫자 크기·출처(개념 < 교과 < 응용 < 사고력 < 심화)로 점수를 매기고, 주차·영역별 순위를 5단계(`l`)로 나눕니다. `build_quiz.py`의 `SLOTS`가 15문제 각 자리의 영역·단계를 정합니다.
- 같은 문제 방지: 마을을 1권 1일차부터 차례로 배정하면서 이미 쓴 문제(질문+그림)를 모두 기억해 다시 뽑지 않습니다. 문제가 모자라면 풀을 늘려 다시 뽑습니다.

새 책(11권 이후)을 추가하려면 `eunwoo_math_code/`에 `bk11.py`를 만들고 `build_quiz.py`의 `NBOOKS`, `BOOK_INFO`, `MODS`를 늘립니다.
