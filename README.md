# 은우의 수학탐험

은우(6살)가 수학책 한 단원을 마친 뒤 아빠와 함께 태블릿으로 푸는 복습 퀴즈 홈페이지입니다.

- 접속: https://kanghyewoo112.github.io/ewmath/
- 구성: 5권 × 30마을(하루에 한 마을). 마을을 통과(10문제 중 7문제를 한 번에 맞히기, 9문제면 별 2개, 10문제면 별 3개)하면 다음 마을이 열리고, 30번 마을을 통과하면 다음 권이 열립니다. 책의 12주를 2~3마을씩 나눠 담습니다.
- 문제: 마을마다 10문제입니다. 1~5번은 복습(쉬운 단계, 앞선 주차 문제 포함), 6~10번은 단계별로 어려워집니다(선행 → 응용 → 도형·측정 → 사고력 → 심화). 연산·사고력·도형·교과·선행·심화 6영역을 모두 섞어 냅니다. 퀴즈를 마치면 풍선 놀이로 마무리합니다.
- 아빠 모드: 위쪽 로고를 3초 안에 5번 누르면 모든 마을이 열립니다. 다시 5번 누르면 꺼집니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 홈페이지 전체 (화면·퀴즈 진행·진행 기록) |
| `data/quiz.js` | 퀴즈 데이터. 직접 고치지 말고 아래 명령으로 다시 만듭니다 |
| `tools/build_quiz.py` | 책 코드(`gen.py`)와 문제표(`probs*.py`)에서 `data/quiz.js`를 만드는 스크립트 |
| `tools/book1_data.py` | 1권 마을별 문제 종류와 확인 문제 (1권은 문제표가 없어서 따로 둡니다) |
| `eunwoo_math_code/` | PDF 교재를 만드는 원본 코드 |

## 매달 책을 새로 만든 뒤 퀴즈 갱신하기

1. 책 코드(`eunwoo_math_code/eunwoo_math_code/`)의 `content*.py`, `probs*.py`를 고쳐서 PDF를 다시 만들고 확인합니다.
2. 퀴즈 데이터를 다시 만듭니다.

   ```bash
   python tools/build_quiz.py
   ```

3. 브라우저에서 `index.html`을 열어 확인한 뒤 커밋하고 push 하면 홈페이지에 반영됩니다.

`build_quiz.py`가 하는 일: 문제표의 글 문제 중 정답이 숫자·짝 고르기인 것은 보기 4개의 터치 문제로 바꾸고, 서술형 답은 아빠와 함께 확인하는 카드로 만듭니다. 연산은 `gen.py`의 생성기로 새로 만들고, 시계·자·도형 그림도 코드로 그립니다. 다음 주차의 계산 종류는 선행 문제로 씁니다.

난이도: 문제마다 종류·숫자 크기·출처(개념 < 교과 < 응용 < 사고력 < 심화)로 점수를 매기고, 주차·영역별 순위를 5단계(`l`)로 나눕니다. 퀴즈의 1~5번은 1~2단계(현재 주차와 앞선 두 주차에서), 6~10번은 단계 3, 3, 4, 4, 5를 `index.html`의 `SLOTS`에서 뽑습니다. 같은 주차를 나눠 쓰는 마을끼리 문제가 겹치지 않도록 마을별로 우선 뽑는 문제를 나누고, 이미 푼 문제는 브라우저에 기록해 뒤로 미룹니다.

새 책(6권 이후)을 추가하려면 `build_quiz.py` 위쪽의 `CONTENT`, `BOOK_INFO`와 `build()`의 책 범위(`range(1, 6)`)를 늘리고, `eunwoo_math_code`에 새 `content`·`probs` 모듈을 추가하면 됩니다.
